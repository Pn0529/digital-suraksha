# Chapter 1: Introduction

## 1.1 Background

The present digital era has expanded the reach of online banking, digital payments, and e-commerce, but it has also increased the risk of cyber fraud. Citizens, students, and senior family members often face fraudulent messages, fake payment requests, impersonation calls, phishing pages, and false investment offers. The repository for this project contains a bilingual awareness portal called Digital Suraksha, which is designed to reinforce safe digital practices, especially for UPI transactions, scam recognition, and cybercrime reporting.

The application is implemented as a responsive web portal using React, TypeScript, Vite, Tailwind CSS, and an Express API. It is focused on practical community relevance by making cyber-safety information accessible in both English and Telugu. The content is intentionally designed to help users verify payment requests before approval, avoid sharing OTPs or PINs, and report suspicious messages or calls.

## 1.2 Problem Statement

Many individuals, particularly non-technical users, are vulnerable to digital scams due to limited awareness of common fraud patterns. Repeated issues include UPI QR-code scams, fake links, fake job or loan offers, phishing websites, and pressure-based tactics such as “digital arrest” calls. These problems can cause financial loss, emotional distress, and a decline in trust in digital transactions.

The project addresses this gap by creating a community-focused, multilingual digital safety portal that explains common cyber fraud patterns, safe practices, and trusted reporting routes. It also provides educational materials and a voice-enabled assistant to make the information more approachable for diverse users.

## 1.3 Need for the Project

There is a strong need for a simple, accessible, and reliable source of cyber-safety information for everyday citizens. In many cases, digital safety guidance is scattered across websites, forwarded messages, and informal channels, which may not be sufficiently accurate or user-friendly.

Digital Suraksha fills this need by providing a centralized information hub with a clear user interface, bilingual support, a grounded knowledge base, downloadable materials, and awareness-focused content designed for citizens with varying levels of digital literacy.

## 1.4 Scope and Relevance to the Community

The project is relevant to the broader community because it supports safer digital transactions, better financial literacy, and faster recognition of fraud attempts. Although the repository does not include formal field-survey data or verified community interviews, the project directly addresses the practical need for accessible cyber-awareness information in local communities.

The system is especially relevant to students, families, senior citizens, and first-time digital users who may need clear guidance before authorizing payments or sharing account information. Its scope remains focused on awareness, prevention, and education rather than formal law-enforcement or financial processing.

# Chapter 5: Methodology

## 5.1 Existing System

Traditional cyber-safety awareness is often fragmented. Citizens may receive information through WhatsApp forwards, social media posts, or informal word-of-mouth. Such communication may be incomplete, inconsistent, or hostile to users who are unfamiliar with online safety concepts. In many cases, there is no centralized bilingual platform that combines practical lessons, safe financial guidance, and reporting channels in one place.

## 5.2 Description of the Proposed Methodology

The proposed Digital Suraksha portal adopts a user-centered design approach and modular content architecture. The application is built to support digital education by combining structured knowledge with an interactive interface.

The system uses:

- a React + TypeScript frontend for the multilingual user experience,
- a Vite build pipeline for fast front-end development,
- an Express server for grounded API responses and knowledge retrieval,
- a local dataset of cyber-safety answers for common scam scenarios,
- browser speech features for voice-guided assistance,
- downloadable public awareness materials stored in the project assets.

## 5.3 Software Requirements

**Software requirements:**

- Node.js and npm
- React 19
- TypeScript
- Vite
- Express
- Tailwind CSS
- Browser with Web Speech API support
- Modern browser such as Chrome, Edge, or Chromium-based browser

**Hardware requirements:**

- Laptop or desktop computer for development and demo
- Mobile-friendly layout for community access
- Microphone-enabled device for voice assistant testing
- Internet connection for browser access (optional for local prototype testing)

## System Workflow and Implementation Details

1. The user opens the Digital Suraksha portal in a modern browser.
2. The application loads a bilingual interface in English or Telugu.
3. The user can navigate to the home page, knowledge library, audio assistant, help center, or download section.
4. The voice assistant accepts spoken input and converts it into text using browser speech recognition.
5. The backend queries a grounded knowledge base for relevant scam-prevention guidance.
6. The result is displayed and spoken back using text-to-speech features.
7. Users can download awareness posters and checklists for offline community education.

## Testing and Validation Evidence

The project implementation was validated as follows:

- Dependency installation: `npm install` successfully completed.
- Production build verification: `npm run build` completed successfully.
- Build result: `✓ built in 27.05s`.
- Local API health endpoint: `GET /api/health` is configured to return a status response for the Express server.

This confirms that the project is functional as a local demonstration build and that the application is ready for further refinement and community deployment.

## Limitations and Assumptions

- The application is a local demo and does not yet include secure cloud deployment or a production database.
- The knowledge base is static and manually maintained; it is not connected to a live data source.
- Voice features depend on microphone support and browser compatibility.
- No real field-survey data or official community response records were included in the repository.
- The project is designed for awareness and education rather than legal or financial processing.

## Expected Impact

The expected impact of the project is to improve digital literacy among citizens, reduce vulnerability to online scams, and encourage safer digital behavior in everyday financial transactions. It is intended as a practical educational tool and outreach platform rather than a stand-alone formal service system.
